this is a catalog of some of the code I've been writing in slowly building a survival game; it's mostly scattered scripts corresponding to input, movement, and inventory systems as well as procedural animation

the main area of growth I've experienced from this project is a high-level understanding of networking (thus far, this repo doesn't contain networking-oriented code; but I learned about topics like RPCs, client prediction, reconciliation, replication, synchronization, and the like through experimentation with a Unity networking library known as FishNet) as well as approaching coding with foresight and the potential downsides of trying to anticipate too many future design features (hence the incomplete nature of the inventory system; I've been trying to anticipate how I would implement a skill system, stat system, item property system, equipment system, and crafting system in a decoupled manner; it's forcing me to familiarize myself with design patterns such as the observer pattern, which appears naturally through C# events, and singleton pattern)
